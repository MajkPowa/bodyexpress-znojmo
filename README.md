Web obsahuje interaktivní vysvětlení EMS, mobilní rezervační tlačítko a odkaz/QR na ověřený Google profil pobočky. Fotografie pocházejí z materiálů sítě BodyExpress a nejsou vydávány za doložený interiér Znojma.

Stripe, Meta Pixel a produkční CAPI jsou vypnuté. GitHub Pages neprovozuje serverový backend. Podpůrné stránky pro budoucí platbu jsou neaktivní příprava; bez Stripe účtu, serveru a konečných podmínek nelze přijímat platby.

Oficiální bodyexpress.cz/znojmo nebyl tímto nasazením změněn. Canonical zůstává na oficiální adrese a tato sdílitelná kopie používá noindex. Nahrazuje dřívější GitHub přesměrování na oficiální web; změna byla výslovně vyžádána uživatelem.

Publikace: main / kořen repozitáře, .nojekyll. Repozitář obsahuje jen statický frontend. Nepatří sem tokeny, .env, objednávky, soukromé dokumenty ani serverové CAPI.
