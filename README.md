# BodyExpress Znojmo

Veřejná statická landing page na GitHub Pages.

https://majkpowa.github.io/bodyexpress-znojmo/

Rezervační tlačítka vedou do oficiálního systému Reservanto pro Znojmo. Reklamní měření je vypnuté. GitHub Pages neprovozuje serverové API ani Conversions API.

Publikace: větev `main`, kořen repozitáře; `.nojekyll`.

Logo, síťové fotografie a fonty pocházejí z veřejných podkladů BodyExpress. Úvodní vizuál je označená AI ilustrace. Síťové fotografie jsou označené jako ukázky EMS a nepředstavují doložený personál nebo interiér Znojma.
